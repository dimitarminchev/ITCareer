# Бит мания
Митко е обзет от бит мания! В това особено състояние той си измисля цяло число n (0 <= n <= 105) и започва да определя колко от битовете в изписването на числата от 0 до n вкл. са 1-ци. За малки стойности това е лесно, но колкото по-голямо става n, толкова повече вече е нужна вашата помощ. 

## Вход
Програмата прочита едно цяло число - n

## Изход
Изведете получените стойности на един ред, разделени с интервал.

## Пример

| Input | Output      | Comment                |
| ----- | ----------- | ---------------------- |
| 5     | 0 1 1 2 1 2 | 0 --> 0 (няма единици) |
|       |             | 1 --> 1 (1 единица)    |
|       |             | 2 --> 10 (1 единица)   |
|       |             | 3 --> 11 (2 единици)   |
|       |             | 4 --> 100 (1 единица)  |
|       |             | 5 --> 101 (2 единици)  |
| ----- | ----------- | ---------------------- |
| 2     | 0 1 1       |                        |
